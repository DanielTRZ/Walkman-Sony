# 📻 Sony Walkman TPS-L2 (Retro CSS Art)

A tribute to the iconic 1979 **Sony Walkman TPS-L2**—the world's first portable cassette player—crafted entirely in **HTML and CSS** with smooth animations.

## ✨ Features & Details
* **Faithful 1:1 Replica** – Featuring the signature blue chassis, silver side panel, orange button, and classic branding.
* **Animated Tape Reels** – The cassette spools continuously rotate to simulate music playback.
* **Glass Glare Effect** – A dynamic light reflection sweeping across the cassette window.
* **Atmospheric Background & Filters** – Dark, synthwave-inspired aesthetics complete with a subtle CRT scanline effect.

## 🚀 Technologies Used
* Pure HTML5
* CSS3 (Flexbox, Keyframes, Pseudo-elements, Gradients)

# 📻 Sony Walkman TPS-L2 (Retro CSS Art)

Projekt kultowego, pierwszego na świecie przenośnego odtwarzacza kasetowego **Sony Walkman TPS-L2** z 1979 roku, odtworzony w czystym **HTML i CSS** z dodatkiem płynnych animacji.

## ✨ Funkcje i detale
* **Wierna replika 1:1** – charakterystyczny niebieski korpus, srebrny panel boczny, pomarańczowy przycisk oraz kultowe napisy.
* **Animowane szpulki** – taśma w okienku obraca się bez końca, imitując odtwarzanie muzyki.
* **Efekt szyby (Glass Glare)** – dynamiczny refleks świetlny przemieszczający się po okienku kasety.
* **Klimatyczne tło i filtry** – mroczny, synthwave'owy klimat z subtelnym efektem skanowania ekranu (CRT).

## 🚀 Technologii użyte
* Czysty HTML5
* CSS3 (Flexbox, Keyframes, Pseudo-elementy, Gradients)
